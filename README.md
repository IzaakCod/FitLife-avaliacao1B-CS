## ⚡ 01. | O QUE É O FITLIFE?

O **FitLife** é um projeto de desenvolvimento web com foco em saúde, fitness e bem-estar.

A proposta é reunir conteúdos sobre exercícios físicos e alimentação saudável em um único ambiente, proporcionando aos visitantes uma experiência simples, organizada e intuitiva.

Mais do que apresentar informações, o projeto representa a aplicação prática de conhecimentos em desenvolvimento Front-end, desde a estruturação das páginas até a implementação de elementos interativos.

> 💡 **A ideia central:** utilizar a tecnologia como uma ferramenta para incentivar escolhas mais saudáveis e uma rotina com mais qualidade de vida.

## ⚙️ 06. | EXECUTANDO LOCALMENTE

Quer conhecer o projeto na prática? Siga os passos:

**1. Clone o repositório**

```bash
git clone https://github.com/IzaakCod/FitLife-avaliacao1B-CS.git
```

**2. Entre na pasta**

```bash
cd FitLife-avaliacao1B-CS
```

**3. Abra no Visual Studio Code**

```bash
code .
```

**4. Execute**

Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
