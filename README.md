## 📌 Sobre o projeto

O **FitLife** é um projeto web desenvolvido com o objetivo de explorar a criação de uma plataforma voltada para o universo fitness.

A proposta é oferecer uma experiência digital que incentive hábitos saudáveis, conectando tecnologia, atividade física e bem-estar em uma interface intuitiva e agradável.

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web, permitindo colocar em prática conceitos de programação, estruturação de páginas e criação de interfaces.

## ✨ Objetivos do projeto

- 🏃 Incentivar a prática de atividades físicas e hábitos saudáveis.
- 🎨 Desenvolver uma interface visualmente agradável e intuitiva.
- 💻 Aplicar conhecimentos de desenvolvimento web na prática.
- 📱 Explorar a criação de páginas adaptáveis a diferentes dispositivos.
- 🚀 Evoluir minhas habilidades como desenvolvedor em formação.

## 🚀 Como executar o projeto

Você pode executar o FitLife localmente seguindo estes passos:

**1. Clone o repositório**

```bash
git clone https://github.com/IzaakCod/FitLife-avaliacao1B-CS.git
```

**2. Acesse a pasta do projeto**

```bash
cd FitLife-avaliacao1B-CS
```

**3. Execute o projeto**

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** no Visual Studio Code.
